Documentação do MulletaFlix

Tudo o que você precisa para instalar, configurar e operar seu servidor de mídia pessoal, conectar o Android e manter sua biblioteca organizada.

Visão geral: o servidor Windows centraliza autenticação, bibliotecas e reprodução. O navegador e o aplicativo Android funcionam como clientes conectados a esse servidor.

Primeiros passos

Para uma instalação nova no Windows, siga esta sequência:

Baixe e instale

Use o instalador EXE da página de downloads. Mantenha o diretório padrão, a menos que sua infraestrutura exija outro caminho.

Abra o servidor

Inicie o MulletaFlix e acesse a interface web local indicada pelo assistente. Na primeira execução, crie a conta administrativa.

Adicione a primeira biblioteca

Escolha o tipo de conteúdo e a pasta que contém seus arquivos. Aguarde a varredura e revise títulos, capas, áudio e legendas.

Conecte seus dispositivos

No Android ou no navegador, informe o endereço do servidor e entre com a conta criada.

Administração

Configuração do servidor

Conta administrativa

Use uma senha exclusiva e forte. Crie usuários separados para as demais pessoas e conceda somente as permissões necessárias.

Pastas de mídia

Prefira uma pasta por biblioteca e evite misturar arquivos temporários, downloads incompletos ou backups com o acervo.

Metadados

Após a primeira varredura, revise o provedor de metadados, nomes de arquivos, imagens, favoritos e histórico.

FFmpeg

Configure o FFmpeg somente quando precisar transcodificar. A reprodução direta consome menos CPU e preserva melhor a qualidade.

Organização

Bibliotecas e nomenclatura

Uma estrutura consistente ajuda o catálogo a identificar os conteúdos e reduz correções manuais.

D:\Midia\Filmes\Nome do Filme (2024)\Nome do Filme (2024).mkv D:\Midia\Series\Nome da Serie\Season 01\Nome da Serie - S01E01.mkv D:\Midia\Musica\Artista\Album\01 - Faixa.flac

Use nomes estáveis, mantenha temporadas separadas e, quando necessário, inclua o ano no nome do filme. Depois de reorganizar arquivos, execute uma nova varredura.

Experiência

Clientes: web e Android

Interface web

Abra o endereço do servidor em um navegador moderno. É a opção mais simples para computadores e TVs com navegador compatível.

Conhecer releases

Aplicativo Android

Instale o APK oficial, informe o servidor local ou público seguro e autentique com seu usuário. O app oferece player, downloads offline, Live TV, SyncPlay e Chromecast quando configurados.

Conectividade

Rede e segurança

Na rede local, use o IP privado do computador servidor. Para acesso externo, prefira uma VPN ou proxy reverso com HTTPS.

Não exponha uma porta HTTP simples diretamente à internet. Use firewall restritivo, senhas fortes, atualizações e um domínio com certificado TLS quando houver acesso remoto.

Rede local

Teste primeiro pelo endereço local e confirme que o firewall do Windows permite o tráfego necessário.

Acesso remoto

Configure VPN ou proxy reverso, valide o certificado e teste fora da rede Wi-Fi antes de compartilhar o endereço.

Player

Reprodução e transcodificação

O MulletaFlix tenta reproduzir diretamente sempre que o dispositivo suporta o formato. Quando não suporta, o servidor pode converter o conteúdo com FFmpeg.

Reprodução direta

Melhor desempenho e menor uso de CPU. Use formatos compatíveis com o dispositivo sempre que possível.

Transcodificação

Necessária para incompatibilidade de codec, resolução, áudio ou legendas. Monitore CPU, memória e espaço temporário.

Áudio e legendas

Selecione a faixa no player. Se uma legenda exigir queima no vídeo, o custo de transcodificação pode aumentar.

Live TV e SyncPlay

Use Live TV quando os canais e o EPG estiverem configurados; o SyncPlay sincroniza a reprodução entre participantes.

Operação

Manutenção e atualização

Faça cópias de segurança antes de atualizar. Preserve configurações, banco de dados e metadados conforme a estrutura da sua instalação.

Leia as notas da release

Confira mudanças, requisitos e incompatibilidades no GitHub antes de aplicar uma atualização.

Faça backup

Salve a configuração e os dados importantes em outro disco ou local protegido.

Atualize com o pacote adequado

Use o instalador para uma instalação nova e o ZIP de atualização para uma instalação existente, seguindo as instruções da release.

Diagnóstico

Problemas comuns

O cliente não encontra o servidor

Confirme que ambos estão na mesma rede, use o IP correto, verifique o firewall e teste o endereço no navegador do dispositivo.

O vídeo trava ou baixa a qualidade

Verifique se está ocorrendo transcodificação, reduza a resolução do stream, teste reprodução direta e confira o desempenho do servidor.

Uma mídia não aparece

Confirme a pasta da biblioteca, permissões de leitura, extensão do arquivo, nomenclatura e execute uma nova varredura.

Preciso de suporte

Consulte as issues do GitHub e envie versão, sistema, passos para reproduzir e logs sem incluir senhas ou tokens.
