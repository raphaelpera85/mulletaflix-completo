Solicitação de títulos ao lado de Favoritos

Servidor
v12.1.2

Solicitação de títulos disponível na Web

O botão de solicitação agora aparece na página inicial React, acima das seções da biblioteca, e abre o formulário com autocomplete. Corrige a diferença entre o template legado e a tela inicial efetivamente usada.

Release
Servidor
v12.1.1

Correções no catálogo e no reconhecimento de livros

Corrige o autocomplete para considerar as raízes reais das bibliotecas STRM e renova o catálogo vazio com mais rapidez. A busca de livros Open Library agora aceita ISBN, IDs e URLs de edição, usa os endpoints atuais e reconhece títulos em nomes de arquivo com prefixos.

Release
Servidor
v12.1.0

Servidor multiplataforma

O servidor passa a ser distribuído para Windows e Linux x64, com instalador Linux para systemd, MariaDB local e FFmpeg. A interface Web segue integrada ao pacote.

Release
