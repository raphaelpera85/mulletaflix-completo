# MulletaFlix — Main Repository

> The Free Software Media System — fork of Jellyfin/Emby, built on .NET 10

---

## Visão Geral

Este é o repositório principal do **MulletaFlix** (solução `MulletaFlix.sln` com 25+ projects).

---

## Build & Run Rápido

```bash
# Build
dotnet build MulletaFlix.sln

# Run server
dotnet run --project MulletaFlix.Server --webdir ../../MulletaFlix-web-master/dist

# Run sem web client
dotnet run --project MulletaFlix.Server --nowebclient

# Tests
dotnet test MulletaFlix.sln
```

## Regras Específicas deste Repo

- **Nullable enabled** — trate warnings como erros
