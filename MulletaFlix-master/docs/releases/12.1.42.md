# MulletaFlix Server 12.1.42 — atualização interrompida com segurança

## Correção

- Se a cópia de uma atualização in-place falhar (Robocopy retorna código 8 ou superior), o atualizador interrompe o fluxo, preserva o pacote extraído para diagnóstico e não inicia o servidor nem o tray com arquivos de versões diferentes.
- A falha que motivou a correção ocorreu durante a atualização de produção: Robocopy retornou 11, os arquivos ficaram incompletos e o processo falhou ao carregar `Emby.Naming.dll`. A instalação foi recuperada reaplicando o pacote íntegro 12.1.40; `/System/Info/Public` voltou a responder HTTP 200 na versão 12.1.40.
