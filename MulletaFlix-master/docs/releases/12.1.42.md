# MulletaFlix Server 12.1.42 — atualização interrompida com segurança

## Correção

- Se a cópia dos arquivos de uma atualização in-place falhar (Robocopy retorna código 8 ou superior), o atualizador agora interrompe o fluxo, preserva o pacote extraído para diagnóstico e não inicia o servidor nem o tray com arquivos de versões diferentes.
- A restauração de backup aplica ao `manifest.json` o limite de leitura de 16 MiB já usado na consulta/listagem; manifesto excedente é rejeitado antes de iniciar alterações nos dados existentes.
- A falha vista em produção foi reproduzida com Robocopy código 11; a instalação foi recuperada reaplicando o pacote íntegro 12.1.40, e as DLLs principais foram confirmadas em 12.1.40.0. `/System/Info/Public` respondeu HTTP 200 na versão 12.1.40.
