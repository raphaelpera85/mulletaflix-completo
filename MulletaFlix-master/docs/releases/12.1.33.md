# MulletaFlix Server 12.1.33 — marca consistente nas notificações

## Correções

- Notificações web agora usam sempre o ícone e badge oficiais do MulletaFlix,
  inclusive avisos de mídia nova. A capa da mídia deixa de substituir a marca
  no ícone da notificação.
- Ícones de ações de instalação e reinicialização usam a mesma marca.
- Removido `notificationicon.png`, asset legado que exibia o símbolo do
  Jellyfin e já não tinha referências ativas após a migração para o branding do
  MulletaFlix.
- Auditoria dos assets do servidor, tray, favicon, tela de login, toolbar e
  screensaver não encontrou outros arquivos visuais Jellyfin em uso. Alguns
  nomes internos de recursos ainda contêm `Jellyfin`; seus bytes correspondem
  ao ícone MulletaFlix.

## Validação local

- Teste focal de identidade da notificação: 1/1.
- Suíte web completa: 419/419 testes em 76 arquivos.
- `npm run build:check`: aprovado.
- `npm run build:production`: aprovado; Vite emitiu avisos de diretivas em
  dependências e imports dinâmicos.
- `npm run verify:build`: 1.924 arquivos válidos; bundle inicial 294,3 KiB
  gzip de orçamento 420 KiB.
- Instalação `npm ci` usou o lockfile atual; npm reportou 11 vulnerabilidades
  em dependências de desenvolvimento (1 moderada, 10 altas). Não foi executado
  `npm audit fix`.

  produção, Linux nativo e instalação/upgrade não foram testados localmente.
