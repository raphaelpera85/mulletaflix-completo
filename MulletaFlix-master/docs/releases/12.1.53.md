# MulletaFlix Server 12.1.53

## Corrections

- IntroSkipper now allows remote `.strm` probes and media scans at least 15 minutes to start and process. A configured timeout above 15 minutes is preserved; `0` remains unlimited. Local FFprobe probes retain their 10-second limit.
- The IntroSkipper FFmpeg settings label identifies concurrency as the number of media files analyzed at once; the supported range remains one or two.

## Validation

- .NET Release tests excluding external integration cases completed without failures.
- IntroSkipper timeout regression tests: 10 passed, 0 failed; its integration suite had 66 passed, 58 skipped, 0 failed.
- IntroSkipper Release build: 0 warnings, 0 errors.
- Windows stage integrity validation passed. The 12.1.53.0 installer and update ZIP were built from the same validated stage.

## Limitations

- No real external streaming host was used to validate startup latency.
- The 58 skipped integration tests did not receive validation credit.
- The Windows installer is unsigned and was not run in an interactive Windows VM.
- Android instrumented and iOS validation were not part of this server release.
