# MulletaFlix Server 12.1.52

## Corrections

- IntroSkipper now resolves local `file:` targets from `.strm` files correctly on Windows, uses the configured FFmpeg path, falls back to container duration when audio duration is unavailable, and limits concurrent media analysis to two items.
- GetAvatar uses the shared ASP.NET Core framework reference, limits remote redirects to the expected host, supports larger image packs, and the web client displays the authenticated user image.
- The Windows installer uses UTF-8 for Portuguese text and adds a protected DuckDNS token field and a button to open DuckDNS.
- FFmpeg debug logs redact credentials and query data from media URIs.
- Production web dependencies were updated; the production dependency audit reports no vulnerabilities.

## Validation

- .NET Release solution: 6,103 passed, 315 skipped, 0 failed across 17 projects.
- IntroSkipper integration tests with disposable MariaDB and FFmpeg: 116 passed, 1 skipped, 0 failed; the STRM end-to-end test verified persisted segments and a maximum concurrency of two.
- Web: 443 tests passed; typecheck, production build, and bundle verification passed.
- DuckDNS token transport: 16 tests passed. NSIS localization tests and Windows stage integrity checks passed.
- Windows installer built as file version 12.1.52.0. The release workflow builds the update ZIP and publishes the platform assets from this tag.

## Limitations

- The Windows installer is unsigned and has not been run through an interactive install/upgrade/uninstall cycle on a disposable Windows VM.
- `.strm` files containing local `file:` targets must come from trusted library operators; target paths are not confined to library roots.
- Android instrumented and iOS validation were not part of this server release validation.
