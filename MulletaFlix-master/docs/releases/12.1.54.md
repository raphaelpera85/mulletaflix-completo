# MulletaFlix Server 12.1.54

## Correção

- A imagem de perfil agora inclui a chave de sessão na URL da imagem, permitindo que o servidor autorize a requisição feita pelo elemento de imagem do navegador.
- Quando a sessão não fornece chave, a URL gerada permanece inalterada.

## Validação

- Suíte web: 444 testes aprovados, nenhuma falha.
- TypeScript: `npm run build:check` concluído sem erros.
- ESLint dos arquivos alterados: concluído sem erros.
- Build web de produção e verificação dos artefatos: concluídos; 1.926 arquivos válidos, payload inicial de 299,8 KiB gzip dentro do orçamento de 420 KiB.

## Limitações

- A leitura da imagem num servidor de produção não foi repetida nesta sessão; validação funcional foi automatizada por teste de componente.
- O instalador e o ZIP do servidor serão produzidos e verificados pelo fluxo de release do GitHub Actions após a publicação da tag.
