# MulletaFlix Server 12.1.44 — prioridade de imagens no idioma configurado

## Correções

- A busca e a escolha de imagens priorizam o idioma configurado para a mídia, comparando códigos sem diferenciar maiúsculas de minúsculas. A variante regional exata (por exemplo, `pt-br`/`pt-BR`) vem primeiro; variantes regionais da mesma língua vêm depois.
- Posters, capas e imagens de fundo usam a mesma regra. Backdrops deixaram de priorizar imagens sem idioma acima das imagens no idioma preferido.
- Inglês continua como fallback, incluindo variantes regionais; imagens sem idioma vêm depois do fallback inglês.
- A lista de imagens disponíveis mantém variantes regionais da língua solicitada em resultados filtrados.

## Validação

- Suítes focadas `EnumerableExtensionsTests`: 14/14 aprovados.
- Suítes focadas de imagens, ordenação de provedores e utilitários TMDb: 72/72 aprovados.
- Build Release Windows x64 e integridade do estágio passaram; instalador e pacote de atualização foram gerados. O ZIP contém `MulletaFlix.dll`, `Emby.Naming.dll`, cliente web, runtime Nebula e `apply-update.ps1`.
- Os testes completos de solução, Linux e CI hospedada não foram executados nesta rodada.
- Homologação formal permanece 2/7 (28,6%). Imagens já salvas localmente não são substituídas automaticamente por esta correção; precisam de atualização de imagens/metadados com substituição habilitada.
