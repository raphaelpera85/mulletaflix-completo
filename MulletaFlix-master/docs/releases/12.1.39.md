# MulletaFlix Server 12.1.39 — encerramento seguro da fila de tarefas

## Experiência web móvel

- No navegador Android, a web sugere instalar o aplicativo MulletaFlix e oferece download direto do APK oficial publicado (`app-v1.3.82`). A opção “Agora não” fica salva no dispositivo. O aviso não aparece dentro do aplicativo nativo.
- O bundle web agora transpila para Chromium 79, base do navegador webOS 6, evitando sintaxe JavaScript mais recente que deixava a tela inicial parcialmente renderizada nesse navegador.

## Correções

- Limita a fila do scheduler de biblioteca para aplicar backpressure em varreduras grandes.
- Mantém registro e descarte dos workers sincronizados; o cleanup cancela workers ociosos e aguarda enqueues já admitidos durante descarte explícito.
- `ApplicationStopping` agora cancela a escrita e a espera de conclusão de enqueues; isso libera produtores bloqueados quando os workers encerram no shutdown do host.
- Uma tentativa de chamar e aguardar `DisposeAsync` dentro de um callback do próprio scheduler falha imediatamente, sem deadlock.
- O progresso reportado reflete a conclusão agregada do lote em vez de sobrescrever progresso com callbacks concorrentes.
- Corrigidas dependências web vulneráveis: DOMPurify `3.4.17`, Vitest/coverage `5.0.5` e Undici transitivo atualizado; `npm audit` ficou sem vulnerabilidades.
