# MulletaFlix Server 12.1.31 — rejeição de backup relacional incompleto

## Correções

- O restore agora compara `DatabaseTables` do manifesto com as tabelas esperadas no contexto relacional central e verifica se cada entrada JSON existe no ZIP.
- O restore rejeita tabelas não declaradas, entradas ausentes e tabelas não suportadas antes de substituir arquivos de configuração, dados ou raiz, e antes de abrir o contexto do banco.
- A rejeição retorna `InvalidDataException`; testes confirmam que configuração existente permanece intacta e que o factory do banco não é chamado.

## Validação executada

- `FullSystemBackup`: 36 aprovados, zero ignorados/falhas.
- `Jellyfin.Server.Implementations.Tests` Release: 1.512 aprovados, 65 ignorados, zero falhas; ignorados incluem Mongo/MariaDB opt-in e casos específicos de plataforma.
- `git diff --check`: aprovado antes do empacotamento.

## Limitações

- Esta correção protege as entradas do contexto relacional central. Não torna o backup integral: outros contextos EF, coleções Mongo/Supabase, snapshots consistentes, criptografia e restore ponta a ponta continuam pendentes conforme `docs/backup-coverage-audit.md`.
- Não houve acesso a banco instalado, produção, restauração completa, host Linux nativo ou playback.
