# MulletaFlix Server 12.1.58

## Correções

- Playback de introduções agora resolve corretamente os itens transitórios retornados pelo fluxo de intros, mesmo quando não pertencem à biblioteca persistente.
- A mídia `.strm` principal começa a ser preparada em cache enquanto a introdução toca, para iniciar a reprodução seguinte mais rapidamente.
- Corrigido o filtro EF Core de segmentos de mídia que podia falhar com HTTP 500 ao carregar segmentos por provider.

O buffer remoto é parcial; o servidor continua lendo a origem conforme necessário. Consulte `homologacao-release-12.1.58.md` para os resultados e limites de validação.
