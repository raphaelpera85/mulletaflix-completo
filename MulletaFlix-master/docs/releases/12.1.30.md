# MulletaFlix Server 12.1.30 — atualização de segurança do frontend web

## Correções e melhorias

- Atualizado o Vite de 7.3.6 para 7.3.7, corrigindo três advisories relacionados ao `launch-editor` no Windows.
- A atualização permanece na mesma linha major do Vite e não altera contratos nem APIs do servidor.
- Auditoria npm: dependências de produção sem vulnerabilidades conhecidas (`npm audit --omit=dev`: 0). A auditoria completa ainda registra 11 vulnerabilidades apenas em dependências de desenvolvimento (1 moderada e 10 altas), que continuam no backlog.
- Inclui as correções de servidor já publicadas na v12.1.29; não foram encontradas alterações adicionais de runtime do servidor desde essa release. Esta versão atualiza o frontend/build e suas dependências de desenvolvimento.

## Validação executada

- `npm run build:check`: aprovado.
- `npm test -- --silent --reporter=dot`: 418/418 testes em 75 arquivos.
- `npm run build:production` e `npm run verify:build`: aprovados; 1.926 artefatos, bundle inicial 294,3 KiB gzip dentro do orçamento de 420 KiB.
- `dotnet test MulletaFlix.sln --configuration Release --no-restore --filter 'FullyQualifiedName!~DramaFindsLiveIntegrationTests'`: exit 0. Implementations: 1.509 aprovados/65 ignorados; Providers: 817/817; API: 763 aprovados/3 ignorados. Os ignorados incluem suites dependentes de MongoDB/MariaDB e plataforma, não contados como aprovados.
- Auditoria de produção: `npm audit --omit=dev --json` sem vulnerabilidades.

## Limitações

- Homologação em produção, inicialização nativa Linux, instalação/upgrade, CI remota e reprodução de mídia não foram executados nesta release.
- A auditoria abrangente e a homologação formal do servidor continuam abertas.
