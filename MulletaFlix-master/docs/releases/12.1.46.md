# MulletaFlix Server 12.1.46 — busca de imagens em todos os idiomas

## Correções

- A busca de imagens TMDb usa o locale preferido e acrescenta seu código ISO 639-1 base, para localizar imagens registradas como `fr` mesmo quando a biblioteca usa `fr-CA`. Mantém imagens sem idioma e inglês como fallbacks, sem duplicar códigos.
- A regra compartilhada atende filmes, séries, temporadas, episódios e coleções, sem preferência fixa por idioma.
- Inicialização do worker Python Nebula aguarda até 120 segundos a sonda de saúde, cobrindo a conexão e confirmação em lotes de bots; a sonda continua exigindo o PID do processo iniciado.
- Se o worker não ficar pronto, o log inclui porta, PID e a última causa observada pela sonda, em vez de mostrar apenas um timeout genérico.
- Saída padrão e erros dos subprocessos Python Nebula são decodificados em UTF-8, preservando acentos e nomes de arquivos nos logs.
- Resposta sequencial HTTP sem bytes agora falha antes de publicar/enfileirar o arquivo; o `.strm` original permanece disponível para nova tentativa.
- Partes de upload retomadas só são reaproveitadas quando SHA-256 dos bytes correspondentes do arquivo local coincide com o hash persistido; partes antigas sem hash são reenviadas com segurança.
- Backup e restauração de configuração foram reforçados com validação de ACL e caminhos, restauração por handles de diretório, journal de recuperação e retomada segura após reinício/falha. O participante do banco do IntroSkipper agora é registrado no contêiner de serviços.
- O refresh de diretórios Nebula mantém operações pendentes persistidas para recuperação após falha/reinício; o serviço de sincronização Supabase recebeu ajustes de retry para falhas transitórias.
- O Centro de Atualizações ignora GitHub Releases marcadas como pré-lançamento, mesmo quando usam tag numérica maior e incluem ZIP; releases estáveis continuam sendo selecionadas normalmente.
- A configuração inicial agora marca como aplicadas somente as migrações de código ausentes do histórico, sem confundir IDs diferentes de migrações EF já aplicadas.
- A migração MySQL `AddImageProviderLanguage` adiciona colunas opcionais para provedor e idioma das imagens, alinhando o schema ao modelo e habilitando persistência desses metadados.
- A validação CI foi ajustada para Linux case-sensitive, testes Nebula em virtualenv isolada, diff/scan com histórico Git completo e Swift 6 no runner macOS 15.
- O verificador do runtime Nebula não exige mais `pystray`, pacote sem uso no código do serviço; isso evita bloquear inicialização e testes headless em Linux.
- O workflow de CI envia a cobertura frontend do diretório real de saída do Vitest (`src/coverage`).
- O bootstrap MySQL cria as tabelas de usuários com a capitalização usada pelo modelo EF, necessária em MariaDB/Linux case-sensitive.
- O CI restaura também o projeto IntroSkipperMigration, referenciado pelos testes mas não restaurado no build da solução.
- O caminho do ProjectReference do IntroSkipperMigration usa a capitalização real `Tools`, necessária para compilação em runners Linux case-sensitive.
- O comando Playwright do CI preserva `Wizard|playlist` como um único argumento de filtro Bash.
- O verificador do runtime Nebula não exige mais `pystray`, pacote sem uso no código do serviço; isso evita bloquear inicialização e testes headless em Linux.

- `NebulaDownloaderStartupTests`: 35/35 aprovados em Release, incluindo diagnóstico de respostas de saúde ausentes, inválidas ou de outro PID. A validação de inicialização no runtime instalado continua pendente.
- `NebulaUploadEngineTests`: 225/225 aprovados em Release, incluindo rejeição de parte retomada com conteúdo alterado e tamanho igual.
- `NebulaDownloaderEngineTests`: 45/45 aprovados em Release, incluindo regressões para rejeitar GET sequencial HTTP 200 vazio e aceitar mídia não vazia quando o tamanho é desconhecido.
- `UpdateInfoControllerTests`: 7/7 aprovados em Release, incluindo seleção estável quando há pré-lançamento numérico com versão maior e ativo ZIP.
- Após integrar backup/restore e refresh Nebula: `FullSystemBackup` 150 aprovados, 16 ignorados por requisitos de plataforma, 0 falhas; `BackupController` 9/9; startup recovery 9/9; OpenTelemetry 3/3; IntroSkipper backup participant 7/7; Nebula refresh/Mongo 26 aprovados e 4 ignorados (Mongo opt-in). Resultados locais não substituem CI nem homologação formal.
- A suíte .NET filtrada antes desta alteração passou com 5.121 aprovados, 68 ignorados e zero falhas; não é evidência específica desta correção. A segunda execução da suíte Providers ficou sem saída e foi cancelada. O teste amplo não será tratado como aprovação desta alteração.
- Build Release de servidor Windows x64, cross-publish Linux x64 e `npm run build:check`/`npm run build:production` anteriores passaram. As mudanças posteriores de inicialização, integridade de upload e downloader foram compiladas pelas suítes .NET, mas os pacotes Windows/Linux ainda precisam ser reconstruídos. Não houve execução do binário em host Linux.
- A API autenticada do TMDb, refresh de mídia, renderização visual, produção e instalação dos pacotes não foram validados nesta sessão. Os testes de NebulaPython não foram executados porque a venv isolada não estava disponível.

## Artefatos

- Os hashes anteriores foram invalidados pela correção do downloader: os três pacotes registrados foram gerados antes do guard contra resposta vazia. Reconstruir e validar os pacotes depois da liberação do CI; não publicar nem instalar os arquivos anteriores.
- Não há instalador ou pacote Linux atualizado para esta revisão.
