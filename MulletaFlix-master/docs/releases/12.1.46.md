# MulletaFlix Server 12.1.46 — busca de imagens em todos os idiomas

## Correções

- A busca de imagens TMDb usa o locale preferido e acrescenta seu código ISO 639-1 base, para localizar imagens registradas como `fr` mesmo quando a biblioteca usa `fr-CA`. Mantém imagens sem idioma e inglês como fallbacks, sem duplicar códigos.
- A regra compartilhada atende filmes, séries, temporadas, episódios e coleções, sem preferência fixa por idioma.
- Inicialização do worker Python Nebula aguarda até 120 segundos a sonda de saúde, cobrindo a conexão e confirmação em lotes de bots; a sonda continua exigindo o PID do processo iniciado.
- Saída padrão e erros dos subprocessos Python Nebula são decodificados em UTF-8, preservando acentos e nomes de arquivos nos logs.

## Validação

- `TmdbUtilsTests`: 27/27 aprovados em Release, cobrindo português brasileiro, francês, japonês, chinês tradicional, espanhol latino-americano, árabe, inglês regional e idioma vazio.
- `NebulaDownloaderStartupTests`: 31/31 aprovados em Release. O código atual ainda não está instalado em produção.
- A suíte .NET filtrada antes desta alteração passou com 5.121 aprovados, 68 ignorados e zero falhas; não é evidência específica desta correção. A segunda execução da suíte Providers ficou sem saída e foi cancelada. O teste amplo não será tratado como aprovação desta alteração.
- Build Release de servidor Windows x64 e cross-publish Linux x64 concluídos; `npm run build:check` e `npm run build:production` passaram. Não houve execução do binário em host Linux.
- A API autenticada do TMDb, refresh de mídia, renderização visual, produção e instalação dos pacotes não foram validados nesta sessão. Os testes de NebulaPython não foram executados porque a venv isolada não estava disponível.
