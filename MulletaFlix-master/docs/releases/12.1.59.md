## Auditoria Windows (2026-11-24)

- Auditoria encontrou falha `realpath`/WinError 121 no cache `.strm` do Nebula standalone e a corrigiu em seu checkout separado. Essa correção não faz parte do pacote candidato MulletaFlix porque o diretório está ignorado pelo Git principal.
- Corrigido o autostart do tray para escrever caminhos com espaços entre aspas e reparar valores antigos; o builder agora usa o projeto de tray versionado no Git principal. Stage Release e tray empacotado foram conferidos.
- O backend instalado estava parado; após o usuário iniciar o tray manualmente, `/health` local e via Nginx retornaram `Healthy` na versão 12.1.58. O valor HKCU Run sem aspas foi corrigido no Registro local.
- Artefatos candidatos locais: ZIP `mulletaflix-update-win-x64.zip`, 419.079.115 bytes, SHA-256 `A491C58C52606460DB1E508089A8F86FA76060161AFE6E909AD8094AA4A11CB3`; instalador `mulletaflix_12.1.59_windows-x64.exe`, 453.916.222 bytes, SHA-256 `23293D26DC650981E15DF3AA3D00FE39004EE5483679BF806A33174A8D463637`, sem assinatura Authenticode.
