# MulletaFlix Server 12.1.37 — corrigida configuração dos provedores XMLTV

## Correções

- Corrigido o carregamento das telas de configuração dos provedores de guia de TV ao vivo. Os imports dinâmicos por caminho de texto não eram empacotados pelo Vite e o navegador tentava resolver identificadores inexistentes, impedindo abrir XMLTV e Schedules Direct.
- O bundle agora registra explicitamente os módulos e templates suportados; tipos de provedor desconhecidos exibem o alerta padrão sem tentar carregar um módulo arbitrário.
- A verificação de artefatos do build detecta regressão de imports não resolvidos e exige os templates de XMLTV e Schedules Direct.

## Validação

- `npm run build:check`: aprovado.
- `npm run build:production`: aprovado; ambos os provedores e templates aparecem como assets do bundle.
- `npm run verify:build`: aprovado; 1.929 artefatos válidos e orçamento do payload inicial aprovado.
- O bundle gerado não contém mais `import()` variável para `components/tvproviders`; a reprodução visual na instalação e o CI hospedado ainda precisam ser confirmados.

## Homologação

- A correção de código foi compilada e os assets foram inspecionados localmente.
- A validação visual com o servidor atualizado e a homologação formal continuam pendentes. Esta release não aumenta os percentuais formais do portal.
