# MulletaFlix Server 12.1.43 — reparo seguro após falha de atualização

## Correções

- Se a cópia de uma atualização in-place falhar (Robocopy retorna código 8 ou superior), o atualizador interrompe o fluxo, preserva o pacote extraído para diagnóstico e não inicia o servidor nem o tray com arquivos de versões diferentes.
- Corrigido o teste de regressão do atualizador: após comprovar falha de cópia, preservação do pacote e ausência de reinício, o teste encerra com código 0. Antes, o texto `PASS` era exibido, mas o processo retornava 1 e bloqueava o workflow.
- A falha que motivou a correção ocorreu em produção: Robocopy retornou 11, os arquivos ficaram incompletos e o processo falhou ao carregar `Emby.Naming.dll`. A instalação foi recuperada reaplicando o pacote íntegro 12.1.40; `/System/Info/Public` voltou a responder HTTP 200 na versão 12.1.40.

## Validação

- `ApplyUpdateFailure.Tests.ps1`: simula Robocopy 11; confirma retorno não zero do atualizador, pacote preservado, nenhum reinício e saída 0 do próprio teste.
- .NET Release: `dotnet test ... --filter "FullyQualifiedName!~Integration"` terminou com código 0; `Server.Implementations` passou 1.520 testes e ignorou 65 casos opt-in/plataforma.
- Nebula Python: `pytest tests -q` passou 660/660 em Python 3.10.
- Web: `npm run build:check` passou, `npm test -- --run` passou 425/425 e `npm run build:production` gerou o cliente.
- Build Release Windows x64 e verificação de integridade do estágio passaram. Instalador NSIS e ZIP de atualização foram gerados; o ZIP contém `apply-update.ps1`, `MulletaFlix.dll`, `Emby.Naming.dll` e `MulletaFlix-web/index.html`.
- O workflow GitHub da tag v12.1.42 não iniciou: a conta está bloqueada por problema de cobrança. Esta release usa os builds e testes locais descritos acima. A plataforma Linux e o workflow hospedado não foram validados nesta execução.
- Homologação formal continua 2/7 (28,6%); esta correção pontual não altera o percentual.

## Artefatos

- Instalador de produção Windows x64 (`mulletaflix_12.1.43_windows-x64.exe`) e pacote de atualização Windows x64 (`mulletaflix-update-win-x64.zip`).
- O pacote Linux não foi gerado nesta execução.
