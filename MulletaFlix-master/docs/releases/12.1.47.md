# MulletaFlix Server 12.1.47 — correção de inicialização do recovery

## Correção

- A inicialização só valida a separação física dos diretórios de restore quando existe um journal de restauração interrompida. Sem restore pendente, diretórios de biblioteca/configuração não bloqueiam o startup por uma validação que não será usada.
- Quando existe journal pendente, a validação fail-closed continua obrigatória antes de verificar e reaplicar o backup; nenhum controle de ACL foi relaxado.
