# MulletaFlix Server 12.1.55

## Correções

- IntroSkipper: arquivos `.strm` ausentes, ilegíveis ou com destino inválido agora são tratados como falha isolada e transitória do fingerprint/scan. Um caminho `.strm` desatualizado não deve interromper a análise dos demais episódios nem ser gravado como mídia sem segmentos.
- CI: movida a seleção do Python temporário para o escopo do step, onde o contexto `runner.temp` está disponível; o teste de contrato também foi corrigido para Windows/CRLF.

## Homologação

- Testes IntroSkipper e E2E com FFmpeg real e MariaDB descartável, testes da solução, build e validações dos pacotes: resultados em `docs/homologacao-release-12.1.55.md`.

- Atualização Windows x64: `mulletaflix-update-win-x64.zip`
