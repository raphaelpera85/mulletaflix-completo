# MulletaFlix Server 12.1.26 — validação de imagens remotas

Esta release corrige a aceitação de respostas HTTP bem-sucedidas que não contêm imagens durante a obtenção de capas e fundos.

## Correção

- Respostas de providers remotos com `Content-Type` ausente ou que não comece com `image/` deixam de ser gravadas como artes de mídia. O fluxo agora trata a resposta como candidata inválida e tenta a próxima imagem disponível, tanto para imagens principais (pôsteres) quanto para fundos (backdrops). Isso evita substituir uma arte válida por uma página HTML de erro ou desafio retornada com HTTP 200.
- Teste de regressão cobre os dois tipos de imagem, rejeição de `text/html`, fallback para a candidata seguinte e salvamento apenas da resposta com MIME de imagem.
