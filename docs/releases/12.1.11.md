# MulletaFlix Server 12.1.11

Versão oficial com inicialização unificada e resiliente dos componentes de conexão remota segura (HTTPS/Nginx), certificados SSL e sincronização DuckDNS.

## Principais Novidades e Correções

- **Gerenciador de Conexão Segura Integrado (`SecureConnectionProcessManager`)**:
  - O servidor MulletaFlix agora valida ativamente o estado do proxy reverso HTTPS e dos certificados SSL ao iniciar.
  - Verifica se a porta 443 já está ativa; caso contrário, assegura o início do serviço Windows `MulletaFlixNginx`.
  - Fallback automático para inicialização direta do processo `nginx.exe` com configuração TLS validada, garantindo operação contínua mesmo sem permissões de serviço do sistema.
  - Encerramento gracioso do proxy gerenciado no encerramento da aplicação.

- **Resiliência de Boot e Reinício do Host**:
  - O proxy HTTPS passa a iniciar automaticamente no boot do Windows e é monitorado contra encerramentos inesperados.
  - O aplicativo de bandeja (`MulletaFlix.Windows.Tray`) foi integrado para sincronizar e disparar o proxy reverso Nginx junto com a inicialização do servidor.
  - Verificação e disparo do cliente oficial DuckDNS em segundo plano para manter o apontamento do domínio `mulletaflix.duckdns.org` sempre alinhado com o IP público da conexão.

- **Confiabilidade e Testes**:
  - Nova suíte de testes unitários para o gerenciador de conexões seguras e resolução de portas.
  - Validação ponta a ponta com resposta `200 OK` através do endpoint público seguro `https://mulletaflix.duckdns.org/System/Info/Public`.
