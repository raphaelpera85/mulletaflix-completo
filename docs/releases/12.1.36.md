# MulletaFlix Server 12.1.36 — Nebula Python e sincronização Supabase

## Correções

- O instalador do runtime Nebula agora recebe `CommonApplicationPaths.DataPath` e mantém a virtualenv Python e seu marker em `<DataPath>/Tools/NebulaPython`, gravável pela conta do serviço. Sem a variável, usa o diretório de dados padrão em `ProgramData` no Windows.
- O Nebula dá erro explícito e interrompe o bootstrap de workers se a verificação/instalação de dependências falhar; não sinaliza o Downloader como iniciado com runtime indisponível.
- O resolvedor prioriza o marker Python no diretório de dados e mantém compatibilidade com o marker legado em `AppContext.BaseDirectory`.
- Paginação Supabase de `nebula_users` exclui logins nulos e vazios, evitando falha da reconciliação por chave inválida.
- Cursor UUID é enviado sem aspas como filtro PostgREST UUID, evitando erro `22P02` no restore de `mulletaflix_users`.
