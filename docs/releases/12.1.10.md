# MulletaFlix Server 12.1.10

Correção focada na página de configuração do Intro Skipper e no carregamento dos segmentos de introdução de episódios de séries.

## Intro Skipper

- Corrige a tela de configuração em branco: JavaScript e CSS agora são fornecidos por rotas próprias de recursos estáticos, compatíveis com as requisições nativas do navegador, sem expor endpoints ou dados de configuração.
- Testes de regressão verificam a entrega dos recursos sem token de API e que os segmentos de introdução ficam associados a cada episódio de série durante a reprodução.

## Nebula e pipeline de produção

- Inclui no repositório o script da configuração Nebula que faltava no build limpo, para que a interface de configuração continue presente nos pacotes de produção.
- Ajusta o pipeline Windows para obter a fonte do tray helper de uma revisão fixa e montar os componentes de runtime exigidos antes de gerar os dois artefatos Windows.

## Validação

- Testes de integração da página/assets do Intro Skipper: 3 aprovados.
- Teste de integração da associação de segmentos ao episódio: 1 aprovado.
- Build de produção web e empacotamento de produção Windows x64 (ZIP e instalador) e Linux x64 concluídos.
- A validação cobre a entrega de configuração e a seleção do segmento por episódio; não representa um teste end-to-end com Telegram ou mídia real em produção.

## Pacotes de produção

- Windows x64: instalador executável e ZIP de atualização.
- Linux x64: pacote self-contained.
- Nenhum APK foi alterado ou publicado neste ciclo.
