# Android reader fixtures

`cbr-ocr-pages.cbr` is a synthetic Android instrumentation fixture. Its two PNG
pages contain only the phrases “MULLETA PAGE ONE” and “MULLETA PAGE TWO”,
rendered for deterministic offline OCR/TTS integration coverage. It contains no
user media or third-party comic content. The RAR4 archive is test-only; WinRAR
is not required by the app or the test runtime.
